Политика конфиденциальности AliVpn

Последнее обновление: 25 сентября 2026 г.

1. Какие данные мы собираем

  • Адрес электронной почты — для авторизации и восстановления пароля
  • IP-адрес — для работы VPN-сервиса
  • Данные об устройстве — модель, версия ОС, разрешение экрана
  • Данные о платежах — через платежную систему ЮKassa
  • Статистика использования — для улучшения качества сервиса

2. Для чего мы используем данные

  • Для авторизации и управления подпиской
  • Для обеспечения работы VPN-сервиса
  • Для обработки платежей и выставления счетов
  • Для улучшения качества и стабильности сервиса
  • Для отправки важных уведомлений и напоминаний
  • Для поддержки пользователей

3. Хранение и защита данных

  • Данные хранятся на защищенных серверах в Supabase
  • Используется шифрование для защиты данных
  • Мы не передаем данные третьим лицам
  • Пароли хранятся в захешированном виде
  • Вы можете удалить свои данные в любой момент

4. Ваши права

  • Право на доступ к своим данным
  • Право на исправление неточных данных
  • Право на удаление данных
  • Право на отказ от рассылок
  • Право на отзыв согласия на обработку данных
  • Право на перенос данных

5. Сроки хранения данных

  • Данные хранятся до момента удаления аккаунта
  • Данные о платежах хранятся 5 лет (по закону)
  • Логи использования хранятся 30 дней
  • Вы можете удалить данные в любой момент
